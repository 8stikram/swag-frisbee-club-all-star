YOSHI — CHARA-DESIGN

Fiche de référence du chara-design de Yoshi — version de PROFIL. Il regarde sur le côté. C'est le seul du roster dans ce cas : tous les autres sont de face. Techniquement ça ne pose aucun problème, le jeu applique un miroir horizontal quand le perso vise à gauche, donc le profil se lit dans les deux sens.

Une erreur de la toute première version a été corrigée : le blanc de la mâchoire était placé derrière l’œil, alors qu’il va sous le museau, à l’avant. C’est pour ça que la tête se lisait comme un aplat vert. Même correction pour la carapace, qui est dans le dos donc à gauche, et le ventre blanc à l’avant donc à droite.

Chaque carte montre le perso entier sur un bout du vrai terrain et à l’échelle du match. Clique une carte pour la monter dans l’aperçu du haut. Le mockup de l’ultime viendra séparément, une fois ce chara-design validé.
